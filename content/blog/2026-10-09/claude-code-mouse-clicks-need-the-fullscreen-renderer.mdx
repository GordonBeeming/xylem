summary: 'Mouse clicks only work in Claude Code when it runs in fullscreen mode. One setting turns it on.'
---

Clicking in Claude Code didn't work for me at all, while [Daniel Mackay](https://www.linkedin.com/in/danieljamesmackay/) had it working fine. The difference is the renderer: Claude Code only listens to the mouse in its fullscreen mode.

To turn it on for every session, add this to `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "tui": "fullscreen"
}
```

Sessions read the settings file when they start, so restart any that were already open. `claude --resume` brings the conversation back.

You can also run `/tui fullscreen`, which saves the same setting and switches the session you're in (`/tui default` goes back), or set `CLAUDE_CODE_NO_FLICKER=1` before launching.
